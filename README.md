# 🎓 EduCloudSMS

A modern cloud-based School Management System built with Django.

EduCloudSMS is designed to help basic and senior high schools digitise their academic and administrative processes. Teachers can record attendance and assessments online, headteachers can approve results, parents can monitor their children's academic progress, and administrators can generate GES-compliant report cards.

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/EmDadzie/EduCloudSMS.git
```

Move into the project

```bash
cd EduCloudSMS
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the virtual environment

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run migrations

```bash
python manage.py migrate
```

Start the development server

```bash
python manage.py runserver
```
